## 해석할 때 주의할 점
- **동시 실행**: 5회를 컨테이너 하나에서 동시에 돌렸다(11-16 PM 결정). `experiment.md` §2 "동시 부하 없음" 조건과 다르다. 봇은 50ms마다 쉬어서 CPU 부하는 작지만, 판 길이 중앙값은 단독 실행(11.1초, PR #28)보다 짧았다(10.4~10.7초). 기준(10초 이상)은 넘는다.
- **이 결과가 보여 주는 것**: 게임 코드가 감시 변수를 모두 합법 구간 안에서 바꾼다는 것, 그리고 규칙(`game/rules.json`)이 정상 변경을 위반으로 보지 않는다는 것. 실제 사용자 입력이나 부하가 큰 환경의 오탐률까지 보여 주지는 않는다.
- **덜 검증된 경로**: 봇은 안전 칸만 열기 때문에 **패배가 0판**이다. `game_state` playing→lost 전이와 패배 쪽 `win-check` 경로는 이 데이터에 없다(단위 테스트 `test_game` "지뢰를 열면 패배한다"와 `test_prediction` enum_transition만 있음). 깃발 회수(+1)도 봇이 하지 않는다.
- **임시 계산**: 채점기(S3-21)가 나오면 같은 원본으로 다시 채점하고, 값이 다르면 채점기를 따른다.
