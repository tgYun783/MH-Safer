# MH-Safer

행위 기반 탐지와 예측을 통한 메모리 변조 탐지 알고리즘 (정보보안 텀프로젝트)

Linux에서 실행 중인 터미널 지뢰찾기 게임의 핵심 변수에 대한 외부 프로세스의 메모리 변조를
- **행위 기반**: 바뀔 타이밍이 아닌데 바뀌었는가
- **예측 기반**: 예측한 값과 다르게 바뀌었는가

두 기준으로 실시간 탐지하고, 탐지 성능과 자원 오버헤드를 측정한다.
