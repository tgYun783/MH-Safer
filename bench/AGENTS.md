# bench/AGENTS.md — T5 자원 측정

루트 `AGENTS.md`를 먼저 읽는다. 이 문서는 `bench/`에서만 필요한 맥락과 주의점이다.

## 이 모듈이 하는 일
libmtd의 추가 자원 사용량을 잰다: 감시 대상 수별 CPU·RSS·대상 지연, 검사 주기 스윕, 배열 비교 비용.
목표(`docs/plan.md` §1): 감시 변수 10개 기준 CPU +10% 이하, 메모리 +20MB 이하. 실용성 판단을 위해 대상 수를 늘려 가며 증가 곡선을 그린다.
담당: 우진(11-30 인수인계 후 PM). 검사 주기 스윕 PoC는 `docs/poc/period-sweep.md`.

## 꼭 지킬 것
- **측정한 값만 기록**: 결과는 `docs/poc/` 또는 측정 결과 CSV에 남기고, 측정 안 한 칸은 "미측정"으로 둔다. 추정치를 측정값처럼 쓰지 않는다.
- **조건을 같이 적는다**: 빌드 타입(Release), 머신·컨테이너, 반복 횟수, 검사 주기 T, 감시 대상 수. 재현 명령을 결과 옆에 둔다.
- 측정은 Release 빌드로. Docker for Mac 등 가상화 환경 수치는 그 사실을 표기한다.
- 벤치는 CI 테스트(`add_test`)로 등록하지 않는다(시간이 길고 수치가 흔들림). 빌드만 CI에서 확인.
